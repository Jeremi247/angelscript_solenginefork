# TODO — P2: what SolEngine has asked for

Scope: changes SolEngine's records name as limits of the library, none of which the engine is blocked on today. Each has a workaround in SolEngine, and each is a feature behind `AS_SOL_` unless upstream takes it ([0002](../decisions/0002-an-engine-feature-is-off-by-default.md)).

The first two change the language rather than the API, so each wants a record weighing the dialect it makes ([SolEngine 0110](https://github.com/Jeremi247/SolEngine/blob/main/docs/decisions/0110-angelscript-is-vendored-from-our-fork.md)).

- [ ] [A system class the compiler knows](P2/compiler-known-system-class.md) — SolEngine refuses a stateful system at load, with no line number.
- [ ] [`const` that reaches through a handle](P2/const-through-handles.md) — a `const` object's handle member still writes.
- [ ] [Metadata that survives into bytecode](P2/metadata-in-bytecode.md) — a build without tools never sees a declaration's attributes.
- [ ] [A collector step that says it has finished](P2/collector-reports-done.md) — an incremental step returns 1 whatever happened.
- [ ] [A free callback that is told the size](P2/sized-free.md) — SolEngine stores it in a 16-byte header on every block.
- [ ] [`&inout` for a value type without unsafe references](P2/inout-value-types.md) — the only switch for it relaxes reference checks engine-wide, and it is due before SolEngine registers a reference type.
- [ ] [Where a type, a property and a global were declared](P2/declaration-positions.md) — SolEngine's load-time refusals cannot name a `file:line`.
- [ ] [Where a collected object was created](P2/cycle-creation-site.md) — a cycle warning names a type and no place. Decided, not started.
